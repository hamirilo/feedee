Go 1.24 で入った新しい標準ライブラリと、実際に使ってみて分かったこと

リリースノートに並んだ変更点のうち、実際のプロダクションコードで効いたものは多くない。ここでは 3 か月運用してみて、明確に書き味が変わった 4 つの API を取り上げる。

1. iterator でループが素直になった

これまで channel と goroutine で書いていた遅延評価の列挙が、標準の iter.Seq で表現できるようになった。リソースリークの心配が減ったのが一番大きい。

「早期 return したときに goroutine が残る」問題を、レビューで指摘しなくてよくなった。

一方で、既存コードの一括置換はおすすめしない。呼び出し側の停止条件が変わるため、テストの粒度によっては差分が見えないまま挙動が変わる。
